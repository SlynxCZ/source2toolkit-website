# META_RES

The result a hook handler returns. It tells SourceHook what to do with the
original function and whose return value wins.

Defined by SourceHook itself, so it is the same vocabulary Metamod plugins
already use — Source2Toolkit does not wrap it in a type of its own.

## Enums

### META_RES

#### Values

- `MRES_IGNORED` = 0 — the handler did nothing
- `MRES_HANDLED` — the handler did something, but the original still runs
- `MRES_OVERRIDE` — the original still runs, but your return value is used
- `MRES_SUPERCEDE` — the original is skipped entirely, your return value is used

## Returning

Do not `return` the value directly — use the macros, which also record the
override value where one applies:

```cpp
RETURN_META(MRES_SUPERCEDE);              // void handlers
RETURN_META_VALUE(MRES_OVERRIDE, false);  // handlers with a return type
```

`RETURN_SH` and `RETURN_SH_VALUE` are aliases for the same thing.

<Callout type="warn">
  `MRES_SUPERCEDE` skips the original **for every remaining handler too**. If
  you called the original yourself and only want to stop SourceHook from
  calling it a second time, supersede is still the right answer — but be aware
  that hooks registered after yours will not see it run.
</Callout>
