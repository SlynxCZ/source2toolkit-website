---
title: "IToolkitApi"
description: "Main entry point for Source2Toolkit API."
---


This interface provides access to:
- Core engine interfaces
- Toolkit subsystems (Commands, Events, ConVars, etc.)
- Logging and console output
- Interface querying and factory access

<Callout type="info">This is the primary interface passed to plugins during initialization.</Callout>

Main API interface for Source2Toolkit.

Provides access to all toolkit subsystems and engine interfaces.

```cpp
api->Commands()->RegisterConCommand(...);
api->Events()->HookGameEvent(...);
```

**Global** `g_ToolkitAPI` · **Header** [`source2toolkit/IToolkitApi.h`](https://github.com/SlynxCZ/source2toolkit-sdk/blob/main/public/source2toolkit/IToolkitApi.h)

### `LoadModule`

```cpp
virtual IToolkitModule* LoadModule(const char* name) = 0;
```

Creates and initialises a module wrapper by name.

The returned object must be released with FreeModule().

| Parameter | Type | Description |
|---|---|---|
| `name` | `const char*` | Module name without extension (e.g. "server"). |

**Returns** [`IToolkitModule*`](/docs/core-api/IToolkitModule) — Heap-allocated IToolkitModule, or nullptr on failure.

### `LoadModuleFromMemory`

```cpp
virtual IToolkitModule* LoadModuleFromMemory(uintptr_t ptr) = 0;
```

Creates and initialises a module wrapper from an address inside it.

The returned object must be released with FreeModule().

| Parameter | Type | Description |
|---|---|---|
| `ptr` | `uintptr_t` | Any address that belongs to the target module. |

**Returns** [`IToolkitModule*`](/docs/core-api/IToolkitModule) — Heap-allocated IToolkitModule, or nullptr on failure.
