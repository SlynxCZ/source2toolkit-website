---
title: "Schema"
description: "Schema system utilities for accessing and modifying entity fields."
---


Provides:
- Runtime field offset resolution (via SchemaSystem)
- Safe access to entity properties
- Automatic network state updates
- Compile-time hashing for fast lookup

<Callout type="info">This system is similar to Source2 schema/netvar access.</Callout>

**Header** [`source2toolkit/schema/schema.h`](https://github.com/SlynxCZ/source2toolkit-sdk/blob/main/public/source2toolkit/schema/schema.h)

## Macros

### `SCHEMA_FIELD`

```cpp
#define SCHEMA_FIELD(type, varName) SCHEMA_FIELD_OFFSET(type, varName, 0)
```

Declares schema field (auto offset + network update).

<Callout type="info">This macro generates a wrapper class that: * Resolves offset via schema * Provides Get/Set * Automatically updates network state * Use this when you want the member's value itself</Callout>

### `SCHEMA_FIELD_POINTER`

```cpp
#define SCHEMA_FIELD_POINTER(type, varName) SCHEMA_FIELD_POINTER_OFFSET(type, varName, 0)
```

Declares pointer schema field. * Use this when you want a pointer to a member

### `DECLARE_SCHEMA_CLASS_BASE`

```cpp
#define DECLARE_SCHEMA_CLASS_BASE(ClassName, offset) \
    private:																		
		typedef ClassName ThisClass;												
		static constexpr const char* m_className = #ClassName;						
		static constexpr uint32_t m_classNameHash = hash_32_fnv1a_const(#ClassName);
		static constexpr int m_networkStateChangedOffset = offset;					
	public:
```

Declares schema-enabled class. * offset != 0 marks a non-entity (embedded) class; the value itself is not used any more

### `DECLARE_SCHEMA_CLASS_INLINE`

```cpp
#define DECLARE_SCHEMA_CLASS_INLINE(className) DECLARE_SCHEMA_CLASS_BASE(className, 1)
```

Declares inline schema class (non-entity). * Use this for non-entity classes such as CCollisionProperty or CGlowProperty * Their NetworkStateChanged is a virtual of the NetworkVar_&lt;field&gt; wrapper the engine embeds them in, not CEntityInstance's; * its vtable slot is found at runtime (NetworkVarStateChanged), so no index is kept per class * Though some classes like CGameRules will instead use their CNetworkVarChainer as a link back to the parent entity
