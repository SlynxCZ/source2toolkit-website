title: "IToolkitCommands"
description: "Command and chat handling interface for Source2Toolkit."
---


Provides functionality for:
- Registering console commands
- Listening to console command execution
- Handling in-game chat messages

<Callout type="info">This system allows plugins to hook into player input via chat or console.</Callout>

Interface for registering and handling commands.

Supports:
- Chat-based commands (player messages)
- Console commands (server or client)
- Command listeners with pre/post execution hooks

<Callout type="info">All commands are owned by a plugin via PluginId.</Callout>

**Interface id** `IToolkitCommands001` (`TOOLKIT_COMMANDS_INTERFACE`) · **Global** `g_pToolkitCommands` · **Header** [`source2toolkit/IToolkitCommands.h`](https://github.com/SlynxCZ/source2toolkit-sdk/blob/main/public/source2toolkit/IToolkitCommands.h)

## Types

### `ChatHandler`

### `CommandHandler`

```cpp
using CommandHandler = std::function<Action(const CCommandContext&, const CCommand&, bool post)>;
```

## Methods

### `RegisterChatListener`

```cpp
virtual void RegisterChatListener(PluginId owner, const char* pchName, ChatHandler handler) = 0;
```

Registers a chat command listener.

<Callout type="info">Only fires for a chat message that starts with one of the configured chat triggers (public or silent, "!" and "/" by default), e.g. "!kick" or "/kick". Plain "kick" typed into chat does not fire it. The trigger is stripped before matching, so args.Arg(0) is the bare name. A silent trigger hides the message; a public one lets it show.</Callout>

| Parameter | Type | Description |
|---|---|---|
| `owner` | [`PluginId`](/docs/core-api/IToolkitApi#pluginid) | Plugin ID that owns the command |
| `pchName` | `const char*` | Command name without a trigger (e.g. "kick", "test") |
| `handler` | [`ChatHandler`](/docs/core-api/IToolkitCommands#chathandler) | Callback executed when command is triggered |

### `RegisterConListener`

```cpp
virtual void RegisterConListener(PluginId owner, const char* pchName, CommandHandler handler, bool post) = 0;
```

Registers a listener for an existing console command.

| Parameter | Type | Description |
|---|---|---|
| `owner` | [`PluginId`](/docs/core-api/IToolkitApi#pluginid) | Plugin ID that owns the listener |
| `pchName` | `const char*` | Existing command name to listen for |
| `handler` | [`CommandHandler`](/docs/core-api/IToolkitCommands#commandhandler) | Callback executed on command execution |
| `post` | `bool` | false to run before the original, true to run after |

**Returns** `void` — Action to control command execution: * Action::Ignore: do nothing * Action::Override: the original still runs; commands return nothing, so this has no further effect. Later pre listeners and all post listeners still fire. * Action::Supersede: block original execution (pre only); the remaining pre listeners and all post listeners are skipped
