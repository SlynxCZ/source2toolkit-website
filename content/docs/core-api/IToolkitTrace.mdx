title: "IToolkitTrace"
description: "Interface and utilities for ray tracing and collision queries."
---


This module provides functionality for:
- Raycasting (line traces)
- Hull traces (box collision)
- Physics queries
- Visibility and hit detection

<Callout type="info">Commonly used for shooting, line-of-sight checks and movement.</Callout>

Interface for performing trace operations.

**Interface id** `IToolkitTrace001` (`TOOLKIT_TRACE_INTERFACE`) · **Global** `g_pToolkitTrace` · **Header** [`source2toolkit/IToolkitTrace.h`](https://github.com/SlynxCZ/source2toolkit-sdk/blob/main/public/source2toolkit/IToolkitTrace.h)

## `CTraceFilterEx`

The filter TraceShapeEx expects when you have an entity to ignore.

The toolkit uses this one internally; it is here because a plugin calling TraceShapeEx needs a CTraceFilter of its own and this covers the ordinary case -- ignore an entity, its owner and everything sharing its hierarchy.

**Inherits** `CTraceFilter`

### Constructors

```cpp
explicit CTraceFilterEx(CBaseEntity* pEntityToIgnore);
CTraceFilterEx();
```
