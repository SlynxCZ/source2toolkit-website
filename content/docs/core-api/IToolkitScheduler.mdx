Provides functionality for:
- Scheduling callbacks for next frame
- Creating repeating or delayed timers
- Managing timer lifecycle

Interface for scheduling tasks and timers.

**Interface id** `IToolkitScheduler002` (`TOOLKIT_SCHEDULER_INTERFACE`) · **Global** `g_pToolkitScheduler` · **Header** [`source2toolkit/IToolkitScheduler.h`](https://github.com/SlynxCZ/source2toolkit-sdk/blob/main/public/source2toolkit/IToolkitScheduler.h)

## Types

### `TimerCallback`

```cpp
using TimerCallback = std::function<void()>;
```

Callback executed by timers

## Methods

### `NextFrame`

```cpp
virtual void NextFrame(PluginId owner, std::function<void()>&& task) = 0;
```

Executes a task on the next frame.

<Callout type="info">Runs once on the next game frame</Callout>

<Callout type="info">Dropped if the owning plugin unloads before the frame arrives</Callout>

| Parameter | Type | Description |
|---|---|---|
| `owner` | [`PluginId`](/docs/core-api/IToolkitApi#pluginid) | Plugin the task belongs to |
| `task` | `std::function<void()>&&` | Callback function |

### `AddTimer`

```cpp
virtual Timer* AddTimer(PluginId owner, float interval, TimerCallback callback, int flags = 0) = 0;
```

Adds a timer.

<Callout type="info">Killed automatically when the owning plugin unloads</Callout>

| Parameter | Type | Default | Description |
|---|---|---|---|
| `owner` | [`PluginId`](/docs/core-api/IToolkitApi#pluginid) |  | Plugin the timer belongs to |
| `interval` | `float` |  | Time in seconds between executions |
| `callback` | [`TimerCallback`](/docs/core-api/IToolkitScheduler#timercallback) |  | Function to execute |
| `flags` | `int` | `0` | Timer behavior flags |

**Returns** [`Timer*`](/docs/core-api/IToolkitScheduler#timer) — Pointer to created Timer

### `KillTimer`

```cpp
virtual void KillTimer(Timer* timer) = 0;
```

Removes a timer.

| Parameter | Type | Description |
|---|---|---|
| `timer` | [`Timer*`](/docs/core-api/IToolkitScheduler#timer) | Timer instance |

## `Timer`

Represents a scheduled timer.

Contains execution data and state for scheduled callbacks.

### Fields

| Field | Type | Description |
|---|---|---|
| `Owner` | [`PluginId`](/docs/core-api/IToolkitApi#pluginid) | Plugin that created the timer, 0 for the toolkit itself. The callback holds code inside that plugin's library, so the scheduler has to drop the timer before the library is closed -- destroying the std::function afterwards calls into unmapped memory. |
| `Interval` | `float` | Interval between executions (seconds) |
| `ExecTime` | `double` | Next execution time (engine time) |
| `Callback` | [`TimerCallback`](/docs/core-api/IToolkitScheduler#timercallback) | Callback function |
| `Flags` | `int` | Timer flags (TimerFlags) |
| `InExec` | `bool` | True while callback is executing |
| `KillMe` | `bool` | Marks timer for deletion |

### Constructors

```cpp
Timer(PluginId owner, float interval, double execTime, TimerCallback callback, int flags);
```

Constructs a timer.
