---
title: "IToolkitCustomHud"
description: "Interface for the panorama custom HUD layouts."
---


`custom_hud_layout` entities render a panorama layout on top of the game HUD. The entity itself is driven through CCSCustomHudLayout; this interface only owns the click callbacks, because the button press arrives as a user message on the core's own hook and has to be routed back to whichever plugin created the layout.

<Callout type="info">Plugins do not normally touch this interface -- CCSCustomHudLayout's HookClick() forwards here for them.</Callout>

Registry of custom HUD click callbacks.

Callbacks are keyed by layout entity, so several plugins may listen on their own layouts at once. Every callback a plugin registers is dropped when that plugin unloads, and the whole registry is cleared on level shutdown along with the entities it points at.

## Methods

### `HookCustomHudClick`

```cpp
virtual ToolkitHookId HookCustomHudClick(CCSCustomHudLayout* pLayout, CustomHudClickHandler handler) = 0;
```

Registers a click callback for one layout entity.

Whose it is, the core reads off the handler (see ToolkitCallback); what a plugin still holds at unload the core drops for it.

| Parameter | Type | Description |
|---|---|---|
| `pLayout` | [`CCSCustomHudLayout*`](/docs/schema/entity/classes/CCSCustomHudLayout) | Layout to listen on |
| `handler` | [`CustomHudClickHandler`](/docs/core-api/IToolkitCustomHud#customhudclickhandler) | A function, an object and a method, or a lambda |

**Returns** [`ToolkitHookId`](/docs/core-api/IToolkitTypes#toolkithookid) — The id UnhookCustomHudClick(id) takes

### `UnhookCustomHudClick`

```cpp
virtual bool UnhookCustomHudClick(CCSCustomHudLayout* pLayout, const CustomHudClickHandler& handler) = 0;
virtual bool UnhookCustomHudClick(ToolkitHookId id) = 0;
virtual void UnhookCustomHudClick(CCSCustomHudLayout* pLayout) = 0;
```

Drops the hook with this handler -- a function or an object and a method; a lambda goes by its id.

Drops the hook HookCustomHudClick() returned the id for.

Drops every callback registered for a layout.

| Parameter | Type | Description |
|---|---|---|
| `pLayout` | [`CCSCustomHudLayout*`](/docs/schema/entity/classes/CCSCustomHudLayout) | Layout to stop listening on |
| `handler` | [`const CustomHudClickHandler&`](/docs/core-api/IToolkitCustomHud#customhudclickhandler) |  |
| `id` | [`ToolkitHookId`](/docs/core-api/IToolkitTypes#toolkithookid) |  |

**Returns** `bool` — true when one was found
