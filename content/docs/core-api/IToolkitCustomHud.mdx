# IToolkitCustomHud

## Methods

### AddClickCallback(owner, pLayout, handler)

Registers a click callback for one layout entity.

<ApiLabel>Parameters</ApiLabel>

- <ApiParam name="owner" type="PluginId" /> — Plugin ID that owns the callback
- <ApiParam name="pLayout" type="CCSCustomHudLayout*" /> — Layout to listen on
- <ApiParam name="handler" type="CustomHudClickHandler" /> — Callback function

### RemoveClickCallbacks(pLayout)

Drops every callback registered for a layout.

<ApiLabel>Parameters</ApiLabel>

- <ApiParam name="pLayout" type="CCSCustomHudLayout*" /> — Layout to stop listening on
