---
title: "IToolkitJSON"
description: "Reading JSON without the plugin owning a JSON library."
---


The toolkit parses; a plugin walks the result through this interface. Nothing library-specific crosses the boundary, so a plugin does not have to vendor a matching JSON implementation or agree with the toolkit on its ABI.

**Interface id** `IToolkitJSON001` (`TOOLKIT_JSON_INTERFACE`) · **Global** `g_pToolkitJSON` · **Header** [`source2toolkit/IToolkitJSON.h`](https://github.com/SlynxCZ/source2toolkit-sdk/blob/main/public/source2toolkit/IToolkitJSON.h)

## Methods

### `Parse`

```cpp
virtual IToolkitJSONDocument* Parse(const char* pszText, int nLength = -1) = 0;
```

Parses text into a document the caller then owns.

Never returns null: on a parse error the document reports IsValid() false and its root reads as null, so walking it is safe without checking.

| Parameter | Type | Default | Description |
|---|---|---|---|
| `pszText` | `const char*` |  | JSON text. |
| `nLength` | `int` | `-1` | Length, or -1 to read up to the terminator. |

**Returns** [`IToolkitJSONDocument*`](/docs/core-api/IToolkitJSON#itoolkitjsondocument) — A document; call Release() on it when done.

## `IToolkitJSONValue`

One node of a parsed document: an object, array, or scalar.

Nodes are owned by the document they came from and stay valid until it is released. Every accessor is total -- asking a string for its integer value, or an object for element 3, returns the default you passed rather than throwing.

## `IToolkitJSONDocument`

A parsed document, and the root node it owns.

Release() invalidates every node reached through it.

### `IsValid`

```cpp
virtual bool IsValid() const = 0;
```

Whether the text parsed. A failed parse still returns a document, whose root reads as null, so a caller can skip the check.

### `GetError`

```cpp
virtual const char* GetError() const = 0;
```

The parser's complaint, or an empty string when IsValid().

### `Root`

```cpp
virtual const IToolkitJSONValue* Root() const = 0;
```

### `Release`

```cpp
virtual void Release() = 0;
```

Frees the document and everything reached through it.
