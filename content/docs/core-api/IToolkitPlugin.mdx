## IToolkitListener

### OnPluginLoad(id)

Called when another toolkit plugin (.stx) is loaded. The id is a toolkit plugin id -- the one "toolkit list" shows.

<ApiLabel>Parameters</ApiLabel>

- <ApiParam name="id" type="PluginId" />

### OnPluginUnload(id)

Called when another toolkit plugin (.stx) is unloaded.

<ApiLabel>Parameters</ApiLabel>

- <ApiParam name="id" type="PluginId" />

### OnMetamodPluginLoad(id)

Called when a Metamod:Source plugin is loaded.  The id is Metamod's, from a different numbering than the toolkit's -- which is why this is not the same callback as OnPluginLoad().

<ApiLabel>Parameters</ApiLabel>

- <ApiParam name="id" type="PluginId" />

### OnMetamodPluginUnload(id)

Called when a Metamod:Source plugin is unloaded.

<ApiLabel>Parameters</ApiLabel>

- <ApiParam name="id" type="PluginId" />

### OnAllToolkitPluginsLoaded()

### OnAllMetamodPluginsLoaded()
