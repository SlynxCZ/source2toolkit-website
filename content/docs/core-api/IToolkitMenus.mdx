---
title: "IToolkitMenus"
description: "Interface and base implementation for menu system."
---


Provides functionality for:
- Defining menus and menu options
- Handling per-player menu instances
- Processing menu navigation and input

Interface for menu system management.

**Interface id** `IToolkitMenus004` (`TOOLKIT_MENUS_INTERFACE`) · **Global** `g_pToolkitMenus` · **Header** [`source2toolkit/IToolkitMenus.h`](https://github.com/SlynxCZ/source2toolkit-sdk/blob/main/public/source2toolkit/IToolkitMenus.h)

## Methods

### `OpenCenterHtmlMenu`

```cpp
virtual void OpenCenterHtmlMenu(PluginId owner, CCSPlayerController* player, CenterHtmlMenu* menu) = 0;
```

Opens a CenterHtmlMenu for a player.

<Callout type="info">Closed for you if the owning plugin unloads while it is open. The menu object and its option handlers live inside that plugin's library, and the next key press would go looking for them there.</Callout>

| Parameter | Type | Description |
|---|---|---|
| `owner` | [`PluginId`](/docs/core-api/IToolkitApi#pluginid) | Plugin the menu belongs to |
| `player` | [`CCSPlayerController*`](/docs/schema/entity/classes/CCSPlayerController) | Target player |
| `menu` | [`CenterHtmlMenu*`](/docs/core-api/IToolkitMenus#centerhtmlmenu) | Menu to open |

|---|---|---|

| `DimBackground` | `bool` | Dims the screen behind the menu. |
| `CaptureInput` | `bool` | With input capture the player gets a cursor and can click the rows, but cannot move or aim while the menu is open.
