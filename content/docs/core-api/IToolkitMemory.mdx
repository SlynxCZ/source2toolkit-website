---
title: "IToolkitMemory"
description: "Toolkit-facing memory address wrapper (mirrors DynLibUtils::CMemory)."
---


Plugins use this value type instead of DynLibUtils::CMemory directly so they remain decoupled from the DynLibUtils headers.  The implementation is identical: every method delegates 1:1 to the underlying arithmetic.

**Header** [`source2toolkit/IToolkitMemory.h`](https://github.com/Source2Toolkit/source2toolkit-sdk/blob/main/public/source2toolkit/IToolkitMemory.h)

## Constructors

```cpp
IToolkitMemory();
IToolkitMemory(const IToolkitMemory&) noexcept = default;
IToolkitMemory(IToolkitMemory&& other) noexcept;
IToolkitMemory(const uintptr_t ptr);
IToolkitMemory(const void* ptr);
```
