# IToolkitHooks

One-line KHook hooks: declared, resolved, attached and taken down from a single
place. Pulled in by `IToolkitPlugin.h`; the walkthrough is in
[Hooking](/docs/hooking).

## Macros

### KHOOK_VIRTUAL(member, function, target, pre, post)

Declares a virtual hook as a class member. The hook's type comes from the
handler named in `pre` / `post`, so the handler is declared above the macro.

<ApiLabel>Parameters</ApiLabel>

- <ApiParam name="member" type="identifier" /> — Member name.
- <ApiParam name="function" type="&Class::Method | int | const char*" /> — Member function pointer (index read from it), a vtable index, or a gamedata offset name.
- <ApiParam name="target" type="&pInstance | KHOOK_VTABLE(...) | nullptr" /> — Pointer to the instance pointer (read at `KHOOK_INIT()`), a whole vtable, or `nullptr` for a manual `Init(...)`.
- <ApiParam name="pre" type="&Self::Handler | nullptr" /> — Callback before the original.
- <ApiParam name="post" type="&Self::Handler | nullptr" /> — Callback after the original.

### KHOOK_MEMBER(member, target, pre, post)

Declares a hook on a member function found by address. The handler takes the
hooked object first, then the function's own arguments.

<ApiLabel>Parameters</ApiLabel>

- <ApiParam name="member" type="identifier" /> — Member name.
- <ApiParam name="target" type="const char* | IToolkitMemory | function pointer | nullptr" /> — A gamedata entry name, an address, a typed function pointer such as an `ADDR_*` getter returns, or `nullptr` for a manual `Init(address)`. Evaluated at `KHOOK_INIT()`, not when the object is constructed.
- <ApiParam name="pre" type="&Self::Handler | nullptr" /> — Callback before the original.
- <ApiParam name="post" type="&Self::Handler | nullptr" /> — Callback after the original.

### KHOOK_FUNCTION(member, target, pre, post)

Same as `KHOOK_MEMBER` for a free function; the handler takes only the
function's own arguments.

### KHOOK_VTABLE(module, name)

A whole vtable as a virtual hook's target: an RTTI class name in a module.

<ApiLabel>Parameters</ApiLabel>

- <ApiParam name="module" type="const char* | IToolkitModule**" /> — The module's name ("server", "engine2", ...) or a pointer to an `IToolkitModule*` filled in at load.
- <ApiParam name="name" type="const char*" /> — RTTI class name.

### bool KHOOK_INIT()

Resolves and installs every hook declared with the macros above. Call in
`Load()`, after `TOOLKIT_SAVEVARS()` and once the instance pointers hooks read
are set. Returns `false` when any hook could not be resolved (each one is
logged); the rest are installed anyway.

### void KHOOK_DESTRUCT()

Detaches every hook and deletes it. Call in `Unload()`.

## Classes

### IToolkitHook

Base of every hook the macros declare. Every instance registers itself on
construction; `KHOOK_INIT()` / `KHOOK_DESTRUCT()` walk that list.

#### bool Init()

Resolves the target given at construction and installs the hook. A hook with
no target (`nullptr`) is left alone and counts as success.

#### void Destruct()

Detaches and deletes the underlying KHook object. Safe to call more than once.

#### bool IsInstalled()

### CToolkitVirtualHook&lt;CLASS, RETURN, ARGS...&gt;

A `KHook::Virtual` plus where it goes.

#### bool Init(pInstance)

Installs the hook on one instance.

- <ApiParam name="pInstance" type="CLASS*" />

#### bool InitGlobal(vtable)

Installs the hook on a whole vtable -- every object sharing it.

- <ApiParam name="vtable" type="IToolkitMemory" />

#### bool InitGlobal(pModule, pszClass)

Installs the hook on the vtable of an RTTI class name in a module.

- <ApiParam name="pModule" type="IToolkitModule*" />
- <ApiParam name="pszClass" type="const char*" />

#### bool InitGlobal(pszModule, pszClass)

Same, with the module loaded by name for the lookup.

#### HookType* operator-&gt;()

The KHook object underneath, so `m_hX->CallOriginal(pThis, ...)` and the rest
of KHook are a `->` away.

#### RETURN CallOriginal(pThis, args...)

Runs the original on `pThis`, bypassing the hook chain.

### CToolkitMemberHook&lt;CLASS, RETURN, ARGS...&gt;

A `KHook::Member` (a function with a `this`, found by address) plus where its
address comes from.

#### bool Init(address)

Places the detour at an address.

- <ApiParam name="address" type="IToolkitMemory" />

#### bool Init(pfnFunction)

Same, from a typed function pointer (an `ADDR_*` getter, say).

#### HookType* operator-&gt;()

#### RETURN CallOriginal(pThis, args...)

### CToolkitFunctionHook&lt;RETURN, ARGS...&gt;

A `KHook::Function` (a free function, found by address) plus where its address
comes from. Same members as `CToolkitMemberHook`, without the hooked object.
