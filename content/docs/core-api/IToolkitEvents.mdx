Provides functionality for hooking into Source2 game events, allowing plugins to inspect, modify, or block events.

<Callout type="info">Events correspond to engine-defined events (e.g. "player_death").</Callout>

Interface for registering game event listeners.

Allows plugins to:
- Listen to engine events
- Modify event data
- Block event propagation

**Interface id** `IToolkitEvents002` (`TOOLKIT_EVENTS_INTERFACE`) · **Global** `g_pToolkitEvents` · **Header** [`source2toolkit/IToolkitEvents.h`](https://github.com/SlynxCZ/source2toolkit-sdk/blob/main/public/source2toolkit/IToolkitEvents.h)

### `GameEventHandler`

```cpp
using GameEventHandler = ToolkitCallback<Action(IGameEvent* event, bool post, bool& dontBroadcast)>;
```

Callback type for game events.

## Methods

### `HookGameEvent`

```cpp
virtual ToolkitHookId HookGameEvent(const char* pchName, GameEventHandler handler, bool post) = 0;
```

Registers a listener for a game event. The same event may be hooked as often as a plugin likes; each handler runs.

Whose it is, the core reads off the handler (see ToolkitCallback); what a plugin still holds at unload the core drops for it.

| Parameter | Type | Description |
|---|---|---|
| `pchName` | `const char*` | Event name (e.g. "player_death") |
| `handler` | [`GameEventHandler`](/docs/core-api/IToolkitEvents#gameeventhandler) | A function, an object and a method, or a lambda |
| `post` | `bool` | false to be called before the engine processes the event, true to be called after |

**Returns** [`ToolkitHookId`](/docs/core-api/IToolkitTypes#toolkithookid) — The id UnhookGameEvent(id) takes

### `UnhookGameEvent`

```cpp
virtual bool UnhookGameEvent(const char* pchName, const GameEventHandler& handler, bool post) = 0;
virtual bool UnhookGameEvent(ToolkitHookId id) = 0;
```

Drops the hook with this handler -- a function or an object and a method; a lambda goes by its id.

Drops the hook HookGameEvent() returned the id for.

| Parameter | Type |
|---|---|
| `pchName` | `const char*` |
| `handler` | [`const GameEventHandler&`](/docs/core-api/IToolkitEvents#gameeventhandler) |
| `post` | `bool` |
| `id` | [`ToolkitHookId`](/docs/core-api/IToolkitTypes#toolkithookid) |

**Returns** `bool` — true when one was found
