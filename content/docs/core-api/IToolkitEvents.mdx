# IToolkitEvents

## Methods

### HookGameEvent(owner, pchName, handler, post)

Registers a listener for a game event.

<ApiLabel>Parameters</ApiLabel>

- <ApiParam name="owner" type="PluginId" /> — Plugin ID that owns the listener
- <ApiParam name="pchName" type="const char*" /> — Event name (e.g. "player_death")
- <ApiParam name="handler" type="GameEventHandler" /> — Callback function
- <ApiParam name="post" type="bool" /> — false to be called before the engine processes the event,
