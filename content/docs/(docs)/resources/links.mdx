## Source code

| Repository | What it is |
|---|---|
| [Source2Toolkit/source2toolkit](https://github.com/Source2Toolkit/source2toolkit) | The toolkit core (the Metamod:Source plugin), the core gamedata and the official sample plugin in `samples/cs2_sample`. |
| [Source2Toolkit/source2toolkit-sdk](https://github.com/Source2Toolkit/source2toolkit-sdk) | The SDK plugins build against: public headers, schema classes, KHook, `tools/deps.py` and the CMake helpers. |

## Downloads

- [Source2Toolkit releases](https://github.com/Source2Toolkit/source2toolkit/releases) — `source2toolkit_<version>-linux.tar.gz` and `source2toolkit_<version>-windows.tar.gz`.
- [Metamod:Source 2.x builds](https://www.metamodsource.net/downloads.php?branch=dev) — required to run the toolkit.

## Community

## Upstream projects

- [alliedmodders/metamod-source](https://github.com/alliedmodders/metamod-source) — Metamod:Source, which loads the toolkit.
- [Kenzzer/KHook](https://github.com/Kenzzer/KHook) — the detour library Metamod, the toolkit and every plugin hook through.
- [alliedmodders/hl2sdk](https://github.com/alliedmodders/hl2sdk/tree/cs2) (`cs2` branch) — the Source 2 SDK headers.
- [SteamDatabase/Protobufs](https://github.com/SteamDatabase/Protobufs) — the game's protobuf definitions.
