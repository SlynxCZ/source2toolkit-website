---
title: "Entity I/O"
description: "Entity I/O system (inputs/outputs) for Source2Toolkit."
---


Provides:
- Access to entity outputs (OnTrigger, OnUse, etc.)
- Hooking system for listening to outputs
- Filtering by entity + classname + output name

<Callout type="info">Equivalent to Hammer I/O system (FireOutput / AcceptInput).</Callout>

**Header** [`source2toolkit/schema/entityio.h`](https://github.com/SlynxCZ/source2toolkit-sdk/blob/main/public/source2toolkit/schema/entityio.h)

## `IEntityIOListener`

Interface for listening to entity outputs.

### `OnEntityOutput`

```cpp
virtual Action OnEntityOutput(const char* pchOutputName, CEntityInstance* pActivator, CEntityInstance* pCaller, float flDelay, bool post);
```

Called when an entity fires an output.

| Parameter | Type | Description |
|---|---|---|
| `pchOutputName` | `const char*` | Output name (e.g. "OnTrigger") |
| `pActivator` | `CEntityInstance*` | Activator entity |
| `pCaller` | `CEntityInstance*` | Caller entity |
| `flDelay` | `float` | Delay before execution |
| `post` | `bool` | false when called before the output fires, true after |

**Returns** [`Action`](/docs/core-api/IToolkitTypes#action) — Action (Action::Ignore / Action::Override / Action::Supersede)
