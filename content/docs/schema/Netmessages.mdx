---
title: "Net message types"
description: "Network message wrappers for Source2 networking system."
---


This file defines strongly-typed wrappers around protobuf-based network messages used by the engine.

Messages are grouped into categories:
- net_* -&gt; core networking
- clc_* -&gt; client -&gt; server
- svc_* -&gt; server -&gt; client

<Callout type="info">All classes inherit from CNetMessagePB.</Callout>

<Callout type="info">Template parameters define message ID, protobuf type, group and flags.</Callout>

**Header** [`source2toolkit/schema/netmessages.h`](https://github.com/Source2Toolkit/source2toolkit-sdk/blob/main/public/source2toolkit/schema/netmessages.h)
